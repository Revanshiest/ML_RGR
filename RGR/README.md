# Предсказание стоимости автомобилей 🚗

Данный репозиторий содержит материалы расчетно-графической работы (РГР) по дисциплине «Машинное обучение». 
Цель проекта — разработать и внедрить ансамблевые модели машинного обучения для предсказания рыночной стоимости автомобилей на вторичном рынке, а также создать интерактивный веб-дашборд для удобного инференса моделей.

## Описание проекта

В проекте реализован полный цикл машинного обучения:
1. **Предобработка данных**: очистка и подготовка тренировочных и тестовых данных.
2. **Обучение моделей**: настройка гиперпараметров с помощью `Optuna` и обучение 6 ансамблевых алгоритмов регрессии (оптимизация по метрике MSE):
   - XGBoost
   - Gradient Boosting
   - CatBoost
   - Random Forest
   - Stacking Regressor
   - Bagging Regressor
3. **Развертывание (Deployment)**: создание веб-приложения с использованием `Streamlit`, которое позволяет пользователям изучить информацию о данных и получить предсказания стоимости автомобиля от обученных моделей в реальном времени.

## Стек технологий

* **Язык программирования:** Python 3
* **Машинное обучение:** Scikit-learn, XGBoost, CatBoost
* **Подбор гиперпараметров:** Optuna
* **Анализ данных:** Pandas, NumPy
* **Веб-дашборд:** Streamlit

## Как запустить проект локально

### 1. Установка зависимостей
Убедитесь, что у вас установлен Python (версии 3.8+). Рекомендуется использовать виртуальное окружение.
Установите необходимые библиотеки из файла конфигурации с помощью pip:
```bash
pip install -r requirements.txt
```

### 2. Обучение моделей
```bash
python train_models.py
```
*Обученные модели автоматически сохранятся в папку `models/`.*

### 3. Запуск дашборда
Для запуска интерактивного веб-приложения используйте встроенную команду Streamlit:
```bash
streamlit run app.py
```
После выполнения команды дашборд автоматически откроется в вашем браузере (по умолчанию на `http://localhost:8501`).
